# 1\. 项目概述

## 1\.1 核心能力

输入微信读书网页书籍 URL，全自动完成**书籍完整数字化采集 \+ AI结构化精读 \+ 全书专业评测**。

最终输出四类标准化产物：

1. 全书纯净逐页截图（无菜单、无遮挡、无弹窗）

2. 全书分页 OCR 文本（每页 PNG→TXT 一一对应、可单页重跑）

3. AI 逐章结构化精读笔记

4. 子Agent 生成**全书五维评分\+专业书评评测报告**

## 1\.2 解决所有生产级痛点

1. **100% 断点续跑**：断网、崩进程、手动关闭，重启精准续跑，不重复工作

2. **永久免登机制**：一次扫码、长期复用浏览器完整登录态（Cookie\+LocalStorage）

3. **零污染截图**：自动清菜单 \+ 人工兜底双保险

4. **页面报错自愈**：加载失败自动重试 3 次，重试耗尽人工介入

5. **图文可追溯**：每页截图、每页文本独立归档，支持单页修复、单页重跑

6. **AI 任务解耦**：流水线采集、章节精读、全书评价由独立模块/子Agent负责，互不干扰

7. **标准化读书产出**：既有逐章学习笔记，又有全书客观评测打分，形成完整阅读资产

## 1\.3 最终架构范式（定稿）

- 整体架构：**1个主控 Workflow（LangGraph 主图） \+ 3个专业子Agent（子图）**

- 开发框架：Python LangGraph（Checkpoint 状态持久化 \+ HITL 人工中断）

- 执行范式：**确定性自动化流程 \+ LLM弱结构化抽取 \+ 子Agent高阶全局推理 \+ 多层人工容错兜底**

### 最终子Agent 划分（最优、不多不少）

1. **ChapterSplitAgent**：章节边界结构化抽取（低温度、强JSON、零编造）

2. **ChapterSummaryAgent**：单章精读结构化笔记生成（忠实原文、固定模板）

3. **BookReviewAgent**：全书全局推理、五维打分、专业书评评测

> 所有浏览器操作、文件IO、OCR、清洗、重试逻辑均为**普通确定性节点**，不做成Agent。

# 2\. 完整工作流链路（最终固定）

```Plain Text
初始化节点
→ 登录态校验节点（自动注入缓存 / 失效人工扫码）
→ 全书逐页截图节点（幂等续跑 + 自动清菜单 + 页面加载重试机制）
    ├─ 菜单遮挡异常 → menu_fix_human_node（人工关弹窗）
    └─ 页面加载报错 → 自动重试3次(3s间隔)
        ├─ 重试成功 → 正常继续
        └─ 重试耗尽 → page_error_confirm_human_node（人工修复页面）
→ 增量分页OCR节点（一页一识别、不重复、图文一一对应）
→ OCR文本清洗节点
→ 子Agent：ChapterSplitAgent（章节切分）
→ 子Agent：ChapterSummaryAgent（逐章总结）
→ 子Agent：BookReviewAgent（全书五维打分+书评）
→ Markdown 统一产物渲染导出
→ 任务结束
```

# 3\. 核心工程机制（所有坑点全覆盖）

## 3\.1 页级幂等 \+ 断点续跑（核心基石）

### 设计原则

- 完全依赖**本地文件状态**，不依赖浏览器进度、不依赖URL、不依赖内存

- 页码严格顺序：page\_no = 1,2,3,4\.\.\.递增

### 进度持久化文件：pages\.jsonl

每行一条原子追加记录：

```JSON
{"page_no":1,"img_path":"0001.png","txt_path":"0001.txt","img_ok":true,"ocr_ok":true}
```

### 幂等判定规则

1. 截图幂等：记录存在 \+ 文件存在 \+ 文件合法 = 跳过

2. OCR幂等：ocr\_ok=true = 跳过识别

### 断网恢复逻辑

1. 读取 jsonl 获取最大完成页码

2. 浏览器回到首页，**空翻页对齐进度**

3. 从断点下一页继续采集，历史数据完全保留

## 3\.2 登录态持久化机制

1. 全局保存 `storage_state.json`，包含：Cookie / LocalStorage / SessionStorage

2. 启动自动注入、DOM检测登录有效性

3. 失效才唤起人工扫码，成功后自动更新缓存

4. 实现「一次登录、长期免登」

## 3\.3 截图防污染机制（双层防护）

1. **自动优先**：截图前检测菜单DOM，ESC自动关闭2次

2. **人工兜底**：无法自动清除 → 暂停流程，用户手动关闭后继续

3. 被污染页面**不标记完成**，自动重跑

## 3\.4 页面加载失败自愈\+兜底机制（最终规则）

### 触发场景

页面空白、加载错误、渲染失败、服务报错

### 自动重试规则

- 单页最大自动重试：**3次**

- 每次重试间隔：**3秒**

- 重试仅针对**当前失败页**，不前进、不跳过

### 兜底策略

- 3次失败仍异常 → 进入 **人工介入中断节点**

- 用户可：手动刷新修复继续 / 终止任务

- 任务终止依然完整保留进度，支持后续续跑

### 双异常节点边界区分

1. **菜单人工节点**：页面正常加载，只是有遮挡

2. **页面报错人工节点**：页面本身加载失败、不可用

# 4\. 三层Agent能力详细定义

## 4\.1 子Agent1：ChapterSplitAgent 章节切分

### 能力

从有序带页码OCR全文中，精准抽取一级章节：标题、起始页、结束页

### 约束

- temperature = 0

- 只摘抄原文，**禁止编造章节**

- 输出严格JSON数组

- 区间不重叠、不越界

## 4\.2 子Agent2：ChapterSummaryAgent 逐章精读总结

### 输出固定结构

- 章节标题

- 核心主旨

- 关键要点

- 重要概念/术语

- 案例论据

- 我的思考

- 待验证疑问

### 约束

- 完全忠实原文

- 可修正OCR错字，不可篡改观点

- 非流水账复述，结构化精读笔记

## 4\.3 子Agent3：BookReviewAgent 全书评测打分（核心高阶能力）

### 五维通用打分体系（1–10分）

1. **逻辑结构性**：全书框架、章节递进、论证闭环

2. **内容干货密度**：有效知识占比、含水程度

3. **观点创新度**：新认知、新模型、反常识价值

4. **落地实用性**：可执行、可复用、可指导工作生活

5. **阅读启发价值**：长期认知升级、思维增益

### 书籍评级规则

- ≥9\.0：神作

- 7\.5–8\.9：优质好书

- 6\.0–7\.4：值得一读

- 4\.5–5\.9：中规中矩

- ＜4\.5：价值较低

### 固定输出报告结构

1. 书籍整体定位

2. 五维评分明细\+依据

3. 综合平均分 \+ 书籍评级

4. 本书核心优势

5. 本书短板与局限性

6. 适合人群 / 不适合人群

7. 高效阅读建议

# 5\. 状态结构定义（最终版）

```Python
class PageResult(BaseModel):
    page_no: int
    img_path: str
    txt_path: str
    img_ok: bool = False
    ocr_ok: bool = False
class ChapterItem(BaseModel):
    title: str
    start_page: int
    end_page: int
    summary: str = ""
class BookReviewResult(BaseModel):
    score_logic: float
    score_density: float
    score_innovation: float
    score_practical: float
    score_inspire: float
    avg_score: float
    level: str
    report_markdown: str
class BookState(BaseModel):
    book_url: str
    book_id: str
    book_name: str
    out_dir: str
    pages: List[PageResult] = []
    max_finish_page: int = 0
    login_valid: Literal["pending", "ok", "fail"] = "pending"
    menu_blocked: bool = False
    blocked_page: Optional[int] = None
    page_load_error: bool = False
    error_page: Optional[int] = None
    retry_count: int = 0
    chapters: List[ChapterItem] = []
    chapter_summaries: List[Dict] = []
    review: Optional[BookReviewResult] = None
```

# 7\. 技术栈最终定稿

- 工作流编排：langgraph \+ langgraph\-checkpoint\-sqlite

- 浏览器自动化：playwright（持久化上下文\+状态导出）

- 离线OCR：rapidocr\-onnxruntime

- 数据模型：pydantic（强约束、结构化校验）

- LLM调用：

    - 章节切分、章节总结：低成本模型

    - 全书评测书评：长文本高精度模型

- 交互：纯终端CLI、无UI

# 8\. 最终架构总结（官方结论）

1. **采集层全确定性**：截图、翻页、OCR、清洗、重试、登录均为代码逻辑，稳定可控

2. **AI层三子Agent解耦**：切分、总结、全书评价各自独立 Prompt、参数、输出规范

3. **三层容错兜底**：自动重试 → 自动清菜单 → 双场景人工中断确认

4. **完全幂等可续跑**：页级最小粒度断点续跑，解决所有中断问题

5. **产物工程化、结构化、可沉淀**

6. **采集与认知彻底分离**：底层稳、上层智能、架构干净、可长期迭代
